\section{Method}
\label{sec:method}

\subsection{Corpora, labels, and splits}
\label{sec:corpora}

We use RAVDESS \cite{livingstone2018ryerson} (24 speakers, 1440 utterances,
1.48\,h) and CREMA-D \cite{cao2014crema} (91 speakers, 7442 utterances,
5.26\,h). Both contain speaker identifiers. The shared labels are angry,
disgust, fear, happy, neutral, and sad. RAVDESS \texttt{calm} is mapped to
\texttt{neutral}; \texttt{surprised} is excluded. The resulting RAVDESS
sample contains 1248 utterances. Table~\ref{tab:corpora} reports the retained
corpus statistics and priors.

\input{../tables/corpora}

Each seed creates \texttt{source\_train}, \texttt{source\_val},
\texttt{target\_adapt}, and \texttt{target\_test} partitions. Speakers are
disjoint across roles. Alignment receives source-train and target-adapt
features only. The target test set is accessed only for scoring. Four
assertions run for every split: speakers do not cross roles, utterance IDs do
not cross corpora, fitted alignment IDs exclude target-test IDs, and the label
map is pure. We use five seeds in both directions. CREMA-D source training is
capped to RAVDESS source-training size by class-stratified subsampling. This
matches source-training size; target adaptation and test sizes remain different.

\subsection{Features and classifiers}
\label{sec:features}

Audio is converted to 16\,kHz mono and peak-normalised. HuBERT Base,
wav2vec~2.0 Base, and WavLM Base are frozen feature extractors
\cite{hsu2021hubert,baevski2020wav2vec,chen2022wavlm}. Each cache stores 13
hidden states of dimension 768. Mean pooling produces one vector per state.
Eight segment means produce a sequence for the Transformer classifier. The
cache also includes 78-dimensional MFCC statistics; this branch is not used in
the reported analyses.

The classifier families are logistic regression, linear SVM, RBF SVM, MLP, and
a segment Transformer. Each family receives 20 source-validation random-search
trials. A failed fit consumes a trial. The classifier does not standardise its
input, because that operation is an alignment condition in this experiment.
The searchable layer conditions are \texttt{last}, \texttt{layer:6}, and a
learned softmax over 13 states. The Transformer uses two seeds in the forward
direction and is excluded from five-seed summaries.

\subsection{Alignment ladder}
\label{sec:ladder}

Let $X_s\in\mathbb{R}^{n_s\times d}$ be source-train features and $X_t$ be
target-adapt features, with means $\mu_s,\mu_t$ and covariances $C_s,C_t$.
All alignment maps are fitted only to $X_s$ and $X_t$.
\begin{description}
  \item[\texttt{none}] $x\mapsto x$.
  \item[\texttt{zscore}] Standardise each domain independently:
    $x\mapsto(x-\mu)\oslash\sigma$.
  \item[\texttt{mean\_shift}] $x\mapsto x+(\mu_t-\mu_s)$.
  \item[\texttt{coral}] $x\mapsto(x-\mu_s)C_s^{-1/2}C_t^{1/2}+\mu_t$.
  \item[\texttt{mkmmd\_diag}] A diagonal affine map fitted by MK-MMD.
  \item[\texttt{mkmmd\_full}] A full affine map fitted by MK-MMD.
\end{description}

For a linear kernel, $\mathrm{MMD}^2(X_s,X_t)=\lVert\mu_s-\mu_t\rVert^2$.
\texttt{mean\_shift} is therefore the linear-kernel MMD minimiser. It is not
labelled MMD in this paper.

CORAL uses
$\widetilde C=C+\varepsilon\operatorname{tr}(C)I/d$ with
$\varepsilon\in\{10^{-4},\ldots,10\}$. The candidate grid also includes a
Ledoit--Wolf covariance estimate \cite{ledoit2004covariance}. For MK-MMD, the
map $(W,b)$ minimises
\begin{equation}
  \mathcal{L}(W,b)=\mathrm{MMD}^2_k(WX_s+b,X_t)
  +\lambda\lVert W-I\rVert_F^2 ,
  \label{eq:mkmmd}
\end{equation}
where $k$ is the sum of Gaussian kernels at $\{0.25,0.5,1,2,4\}$ times the
median pairwise distance \cite{gretton2012kernel}. The diagonal rung restricts
$W$ to the diagonal. We search $\lambda\in\{10^{-3},\ldots,10^2\}$, optimise
for 200 Adam steps \cite{kingma2015adam}, and initialise from the corresponding
moment-matching solution. A non-improving optimisation reverts to that
initialisation and records the fallback.

\subsection{Diagnostics, selection, and inference}
\label{sec:discrepancy}

We report marginal MK-MMD$^2$ after alignment and normalise it by the mean
absolute statistic from random half-splits of the aligned source. We compute it
in two frames. The own-geometry frame estimates bandwidth after each alignment.
The reference frame applies one ZCA map fitted to unaligned source-train
features before every measurement. We also compute class-conditional MMD within
each label, excluding a class when either sample has fewer than 50 utterances.
The class-conditional statistic uses target labels only in post-hoc analysis.
It is not supplied to alignment or selection.

Validated selection chooses the highest source-validation macro-F1 within each
(pair, seed) and scores that configuration once on target-test. Oracle selection
is the highest target-test score in the evaluated grid and is reported only as
an upper bound. Within each ladder rung, CORAL $\varepsilon$ and MK-MMD
$\lambda$ are selected on source validation before target scoring.

Macro-F1 is the primary metric. Chance and majority floors are computed from
each realised target-test prior. Intervals use a
paired cluster bootstrap over target-test speakers and seeds with 2000
replicates \cite{cameron2008cluster}. The pre-specified primary family contains
five ladder-versus-\texttt{none} contrasts and two layer contrasts in each
direction. Holm correction is applied across those 14 tests
\cite{holm1979sequential}.

The frozen main grid contains 4986 runs. A 13-layer sweep contains 2340 runs,
the CORAL shrinkage probe contains 120 runs, and the shift decomposition
contains 120 records. No reported run failed.
