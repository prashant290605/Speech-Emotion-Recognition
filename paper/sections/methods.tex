\section{Method}
\label{sec:method}

This section describes the experimental design. Where a design choice was
contestable, we state the alternative and the reason for rejecting it.
Figure~\ref{fig:pipeline} summarises the pipeline and the retrospective audit.

\subsection{Corpora and label space}
\label{sec:corpora}

We use two English corpora, RAVDESS \cite{livingstone2018ryerson} and CREMA-D
\cite{cao2014crema}, whose statistics are given in Table~\ref{tab:corpora}.
Both are publicly available, both provide speaker identity for every utterance,
and their categorical label sets share a six-class intersection that is large
enough to evaluate per-class transfer. The pairing also admits a source-size
control. Capping the larger training split to the size of the smaller one
allows each direction to be run at a matched training-set size
(Section~\ref{sec:splits}), so a reported asymmetry between directions is not
attributable to source-training-set size alone. Both directions are evaluated.
Both corpora contain acted rather than spontaneous speech, which limits the
scope of the conclusions (Section~\ref{sec:limitations}).

The shared label space is the six-class intersection
$\{$angry, disgust, fear, happy, neutral, sad$\}$. Classes are indexed in
alphabetical order, which is also the order of the confusion matrices in
Supplementary Section~S6. Two mapping decisions affect the class priors and are
stated explicitly because they are contestable. First, \emph{RAVDESS
\texttt{calm} is merged into \texttt{neutral}}, because calm exists only in
RAVDESS and cannot transfer. Merging gives neutral 288 utterances against 192
for every other class, whereas dropping calm would leave neutral with 96.
Neither option is balanced. The original speech subset is also not balanced
across all eight labels: neutral has 96 utterances, while each other label has
192. Second, \emph{RAVDESS \texttt{surprised} is excluded}, because it has no
CREMA-D counterpart. This removes 192 RAVDESS utterances, whereas all CREMA-D
utterances are retained.

The resulting class priors are close but not identical
(Table~\ref{tab:corpora}). The neutral mapping changes these empirical priors,
but it does not establish that all corpus differences arise from the mapping.
Two pre-specified controls test whether the aligned-versus-unaligned conclusion
depends on this mapping (Section~\ref{sec:results-robustness} and Supplementary
Section~S1). Prior divergence and standard label-shift corrections are reported
in Supplementary Section~S2.

\subsection{Splits and leakage control}
\label{sec:splits}

Each corpus pair is partitioned into four roles. The source corpus yields
\texttt{source\_train} and \texttt{source\_val}, and the target corpus yields
\texttt{target\_adapt} and \texttt{target\_test}. Partitioning is
\textbf{speaker-disjoint} throughout, so no speaker appears in more than one
role.

The separation between \texttt{target\_adapt} and \texttt{target\_test} is the
central design constraint. Alignment methods require target-domain features by
construction, and they receive \texttt{target\_adapt} only.
\texttt{target\_test} is read exactly once per run, at scoring time, and never
by any fitted object. This constraint is enforced rather than merely described.
Every alignment object records the identifiers of the utterances it was fitted
on, and an assertion checks the \emph{real fitted object in every run}. Model
selection likewise never sees target data. The selection routine receives no
target features, and the caller computes the target score afterwards from the
already selected model. Four leakage assertions hold over all 20 splits
(4 pairs $\times$ 5 seeds). No group appears in more than one split within a
corpus, no utterance appears in both a source and a target split,
\texttt{target\_test} never appears in any fitted alignment object, and the
label mapping is a pure function. Table~\ref{tab:floors} lists the split sizes,
which vary slightly across seeds within the speaker-disjoint constraint.

\paragraph{Matched-$n$ reverse direction.} The two directions differ sixfold in
training-set size, so any asymmetry between them would be confounded with the
amount of source data. We therefore cap \texttt{source\_train} at the size of
the smaller direction for each seed, which subsamples CREMA-D from 5972 to 988
utterances. The subsample is stratified by class with largest-remainder
allocation, so the class prior is preserved to within one utterance per class.
It is drawn from within the existing speaker-disjoint split, so utterances are
only removed and never moved between roles. Every leakage guarantee therefore
still holds, and the cap is derived per (pair, seed) rather than hard-coded.
\textbf{Both directions reported in this work are matched in source-training
size only}, and a full-$n$ reverse arm was not run. Source-validation,
target-adaptation and target-test sizes remain different between directions.
This control therefore removes one important data-quantity confound, but it
does not license attributing every directional asymmetry to corpus properties.

\subsection{Features}
\label{sec:features}

Audio is resampled to 16\,kHz mono and peak-normalised. Three self-supervised
base models are used as feature extractors: HuBERT Base \cite{hsu2021hubert},
wav2vec 2.0 Base \cite{baevski2020wav2vec} and WavLM Base \cite{chen2022wavlm}.
Each provides a CNN encoder output and twelve transformer layers, that is,
13 hidden states of dimension 768.

\textbf{All 13 layers are cached}, not only the final one. Final-layer pooling
is the common default, and caching every layer makes depth a searchable
condition instead. Section~\ref{sec:results-aggregation} shows that, in this
study, this choice is worth more than any choice \emph{among} alignment
methods, although less than the decision to align at all. A practitioner who
keeps the default layer while tuning the alignment method therefore tunes the
axis with the smaller observed differences.

Two poolings are stored. \emph{Mean pooling} over time gives one
768-dimensional vector per utterance and layer, which the four non-sequential
classifiers use. \emph{Segment pooling} into eight uniform temporal segments
gives an $8 \times 768$ sequence, which provides genuine sequence structure for
the Transformer head. This structure is the reason for including the
Transformer arm, and it requires eight times the storage. Features are
extracted at batch size 1, so no utterance is padded to the length of a longer
neighbour. Padding would place silence inside the pooled average. It would also
do so unevenly across corpora, because RAVDESS utterances are on average
$1.16$\,s longer than CREMA-D utterances.

\subsection{The alignment ladder}
\label{sec:ladder}

The core comparison contains six feature-space conditions. We retain the term
``rung'' as a condition label, not as a claim that these are nested
moment-matching interventions (Section~\ref{sec:affine-factorisation}). Let
$X_s \in \mathbb{R}^{n_s \times d}$ be the source-train features and $X_t$ the
\texttt{target\_adapt} features, with means $\mu_s, \mu_t$ and covariances
$C_s, C_t$. All six rungs are fitted on $X_s$ and $X_t$ only.

\begin{description}
  \item[\texttt{none}] The identity. $x \mapsto x$.
  \item[\texttt{zscore}] Per-dimension standardisation of each domain to zero
    mean and unit variance: $x \mapsto (x - \mu)\oslash\sigma$ within each
    domain. Matches the first and second marginal moments per dimension, with
    no cross-dimension terms.
  \item[\texttt{mean\_shift}] $x \mapsto x + (\mu_t - \mu_s)$. Matches the
    first moment only.
  \item[\texttt{coral}] Whitening by the source covariance and recolouring by
    the target covariance \cite{sun2016deep}:
    $x \mapsto (x - \mu_s) C_s^{-1/2} C_t^{1/2} + \mu_t$. Matches the first and
    second moments, including cross-terms, in the unregularised idealisation.
    With shrinkage, the identity is $M^\top\tilde C_sM=\tilde C_t$, so the
    empirical covariances do not necessarily match exactly.
  \item[\texttt{mkmmd\_diag}] A learned diagonal affine map minimising a
    multi-kernel MMD objective, defined below.
  \item[\texttt{mkmmd\_full}] The same objective with a full matrix $W$.
\end{description}

\paragraph{Mean matching.} For a linear kernel, the squared distance between
empirical kernel means is $\lVert\mu_s-\mu_t\rVert^2$. Within translations,
its minimising offset is $\mu_t-\mu_s$. Among unrestricted affine maps, this
criterion does not uniquely select a translation, because any matrix $A$ can
match the means with offset $\mu_t-\mu_sA$. The empirical-mean expression is
not the unbiased finite-sample estimator used for the RBF diagnostics. We
therefore name the operation \texttt{mean\_shift}, not ``MMD''.

\paragraph{Regularisation of CORAL.} With $d = 768$ and roughly one thousand
source-train samples, the rank bound $\min(d,n-1)$ does not itself imply
singularity. Shrinkage stabilises whitening when small eigenvalues make it
ill-conditioned. The shrinkage is scale-aware and anchored to the mean
eigenvalue, $\tilde{C} = C + \varepsilon\,\frac{\mathrm{tr}(C)}{d} I$, because a
fixed absolute ridge means something different for every backbone and layer.
$\varepsilon$ is a \emph{searched} axis over $\{10^{-4}, \ldots, 10\}$ in
decades, selected on \texttt{source\_val} and recorded on every row, with a
Ledoit--Wolf variant \cite{ledoit2004covariance} as a parameter-free
alternative. Condition number and effective rank are recorded after
regularisation. A matrix that is still singular after regularisation raises an
error rather than being pseudo-inverted.

\paragraph{Multi-kernel MMD.} The two MK-MMD rungs learn an affine map
$(W, b)$ minimising
\begin{equation}
  \mathcal{L}(W, b) \;=\;
  \mathrm{MMD}^2_k\!\left(X_s W^\top + b,\; X_t\right)
  \;+\; \lambda \lVert W - I \rVert_F^2 ,
  \label{eq:mkmmd}
\end{equation}
where the implementation stores $W$ as the transpose of the row-vector map
used in Section~\ref{sec:affine-factorisation}, $k$ is a sum of Gaussian
kernels at bandwidth multipliers $\{0.25, 0.5, 1, 2, 4\}$ of the median
pairwise distance \cite{gretton2012kernel}, and $\mathrm{MMD}^2$ is the
unbiased estimator. \texttt{mkmmd\_diag} constrains $W$ to be diagonal, and
\texttt{mkmmd\_full} does not. The identity anchor regularises a full matrix
with $\approx 590$k parameters fitted on about a thousand source samples. It
penalises $W-I$ but not $b$, so even an ideal large-$\lambda$ limit leaves a
translation to optimise and does not necessarily recover \texttt{none}. No
asymptotic optimisation guarantee is claimed for the finite-step procedure.
$\lambda$ is searched over $\{10^{-3}, \ldots, 10^{2}\}$ in decades.
Optimisation uses Adam \cite{kingma2015adam} for 200 steps at batch size 256,
warm-started from the CORAL solution (full) or a diagonal moment match
(diagonal), with a parameter-count-normalised learning rate.

\paragraph{Acceptance check and fallback.} An unpenalised MMD check on the
first 400 observations compares the fitted candidate with its warm start. When
the candidate worsens this check, the returned map reverts to the warm start.
The check differs from the penalised minibatch training objective, so a
rejection is not proof that the training objective failed to improve. Across
the main grid, the check rejects the candidate in \textbf{64.9\%} of
\texttt{mkmmd\_diag} runs and \textbf{55.2\%} of \texttt{mkmmd\_full} runs. In
those cells the fitted map is the warm start, namely the diagonal moment match
or CORAL, respectively. Reporting either as a distinct learned map would
overstate what was fitted. These rejection rates qualify every MK-MMD result in
this work. The results describe the evaluated affine maps under the stated
warm start and optimisation budget, and they do not establish what a
differently optimised MK-MMD map would achieve. Supplementary Section~S8
records the procedure and the learning-rate derivation.

\subsection{Measuring distribution discrepancy}
\label{sec:discrepancy}

Alignment methods are usually justified by the discrepancy they remove, so the
discrepancy statistic must be specified as carefully as the methods. We report
two quantities. The first is the raw unbiased $\mathrm{MMD}^2$ between the
aligned source and target features. The second is an effect size, which divides
the raw $\mathrm{MMD}^2$ by the mean absolute $\mathrm{MMD}^2$ over five random
splits of the source features into halves. The absolute value is required
because the unbiased estimator has zero mean under the null hypothesis, so its
signed mean cannot serve as a denominator. The effect size aids the
interpretation of finite-sample variation, but it does not replace the raw
statistic.

\paragraph{A common reference geometry.} For the ladder diagnostic, one ZCA
basis is derived from the unaligned \texttt{source\_train} features with
shrinkage $\varepsilon = 10^{-2}$. One median RBF bandwidth is then derived from
the same source-train features in that basis. Both quantities are fixed before
an alignment map is fitted, and they are applied identically to every rung for
that pair, seed, backbone and layer aggregation. The raw trajectories are
therefore compared under one stated kernel and coordinate system. The shrinkage
avoids amplifying near-null directions of the source covariance. A
scale-changing map can nonetheless drive a fixed-bandwidth RBF kernel into
saturation. We report this failure mode rather than treating a near-zero
statistic as evidence of distributional equality. Each MMD evaluation uses a
seeded cap of 128 utterances per sample set. The cap is identical for the
marginal, class-conditional and null computations, and it is recorded in every
diagnostic row.

\paragraph{Adaptive geometry as a sensitivity analysis.} We separately report
an own-geometry calculation that derives the median bandwidth from each
compared feature pair. The 13-layer frame-sensitivity sweep holds the ZCA basis
fixed while recomputing this adaptive bandwidth. We call this a
\emph{reference-basis} calculation rather than a fully fixed reference
geometry. The two procedures answer different measurement questions, so
neither is treated as the unique definition of distributional closeness.

\paragraph{Proposition: median-heuristic scale invariance.} Let
$\hat\sigma(X,Y)$ be the median pairwise Euclidean distance used by the RBF
kernel. For a nonzero scalar $a$,
$\hat\sigma(aX,aY)=|a|\hat\sigma(X,Y)$ and therefore
\begin{equation}
  k_{|a|\hat\sigma}(ax,ay)=k_{\hat\sigma}(x,y).
  \label{eq:median-scale-invariance}
\end{equation}
Each pairwise distance gains the factor $|a|$, which proves the first identity.
Substitution in the RBF exponent proves the second. Thus an adaptive
median-heuristic MMD is invariant to a global rescaling applied to both
samples. This property does not extend to an arbitrary affine map or to a map
applied to only one sample.

\subsection{Classifiers and the search budget}
\label{sec:classifiers}

Five families are evaluated: logistic regression, a linear SVM, an RBF SVM, an
MLP and a small Transformer head over the 8-segment sequence. Each family
receives \textbf{exactly the same budget of 20 random-search trials}, and the
trial count is recorded on every result row. This controls the number of
trials, not effective model capacity or the coverage of equally favourable
settings. Hyperparameter candidates are drawn by seeded random search. A failed
fit receives a score of $-\infty$ and is not replaced by an additional draw.

Two further constraints apply. First, \textbf{no classifier standardises its
inputs internally}. This preserves the raw-coordinate baseline. A scaler fitted
on source training data and shared across domains would be a different control,
and it would not equal domain-wise \texttt{zscore}. Consequently, this grid
does not isolate alignment from classifier conditioning. Second, the iteration
cap of the iterative solvers is a fixed convergence budget ($2\times10^4$)
rather than a searched hyperparameter, because searching it would let a trial
win selection by stopping early rather than by fitting better. Convergence is
asserted rather than warned about. A fit that reaches the cap is recorded as a
failed trial and cannot be selected. Across the whole grid,
\textbf{0 of 99{,}720 trials failed to converge}.

Layer aggregation is a searched condition with three settings: \texttt{last}
(the common default), \texttt{layer:6} (a fixed mid-stack layer) and
\texttt{weighted} (a softmax over all 13 states, learned jointly with the
head). The \texttt{weighted} setting is implemented only for the two PyTorch
families, whose training loops jointly optimise the layer weights and the head.
It is not searched for the scikit-learn classifiers.

The Transformer arm is a deliberately \textbf{reduced-seed arm}, with two
seeds, the primary direction only and one inner-grid setting per rung. Its
per-cell cost is 15--40 times that of the other families, and running it at
full width would have required more compute than every other axis combined.
The full-grid headline and ladder summaries include its available cells, so
the forward candidate set is not identical across seeds. The Transformer arm is
excluded from the matched-direction comparison (Supplementary Section~S3) and,
by construction, from the translation audit.

\subsection{Selection protocol}
\label{sec:selection}

We report two selection protocols side by side, and the difference between
them is one of the results of this work. \textbf{Validated} is the
configuration with the highest \texttt{source\_val} macro-F1 within a given
(pair, seed), scored on \texttt{target\_test}. It is what a practitioner could
obtain without any target labels. \textbf{Oracle} is the highest
\texttt{target\_test} macro-F1 present in the grid for that (pair, seed). It is
a \textbf{post-hoc target-selected benchmark that is unavailable to the
deployable source-only protocol}. The validated-to-oracle difference is called
the \emph{oracle gap}. It does not identify a causal effect of source-side
selection, because it also contains finite-target-sample noise, the effect of
search-space size, and optimism from maximising the target score. Reporting
only the oracle would amount to selecting on target scores, which makes a
method look as good as its best run.

\paragraph{Unequal inner grids in the ladder summary.} Each result row already
contains the best of its classifier family's 20 source-validation trials. For a
ladder summary, we then hold (pair, seed, backbone, layer aggregation,
classifier family) fixed and select the rung's best remaining inner setting
($\varepsilon$ for CORAL or $\lambda$ for MK-MMD) by \texttt{source\_val}
macro-F1. Only the target predictions of these selected cells enter the paired
cluster bootstrap. The row counts in Table~\ref{tab:ladder} are therefore
candidate rows before this second selection, not equally weighted observations
in a rung mean. They differ because the rungs have different inner grids.

\subsection{Metrics, baselines and inference}
\label{sec:metrics}

The primary metric is macro-F1 on \texttt{target\_test}. Accuracy and
unweighted average recall are also recorded on every row. Every performance
number is reported against two baselines. The chance baseline is the expected
macro-F1 of a uniformly random classifier given the realised target-test
priors, and the majority baseline is the macro-F1 of a majority-class
predictor. Both are computed analytically on every row rather than by
simulation, and Table~\ref{tab:floors} lists them for both directions. A
macro-F1 below the chance baseline is below the expected score of a random
classifier. Because the chance baseline differs between the two transfer
directions, macro-F1 is always reported separately for each direction and is
never averaged across directions.

\paragraph{Intervals.} Target-score intervals come from a \textbf{paired
cluster bootstrap} with 2000 replicates \cite{cameron2008cluster}. Each
replicate draws the five seed identifiers with replacement. For each drawn
seed, it then draws that seed's target-test speakers with replacement and keeps
every utterance of each selected speaker. Both arms of a comparison use the
same seed and speaker draws before their macro-F1 difference is formed. The
procedure therefore resamples the split, search and initialisation variation
carried by seeds and the clustered target-test variation carried by speakers.
It never resamples individual utterances independently.

\paragraph{Interval for the source-selected summary.} The paired cluster
bootstrap requires a fixed arm, that is, a condition that can be recomputed on
any resampled set of speakers and seeds. The source-selected summary in
Table~\ref{tab:headline} is not such an arm. Its value for a seed is the target
macro-F1 of \emph{whichever} configuration source-side validation chose on that
seed, and the chosen configuration differs across seeds
(Section~\ref{sec:results-selection}). Each seed therefore contributes one
number that describes a complete deployment decision, and the five numbers are
summarised by their mean and a 95\% $t$-interval over seeds. This interval
estimates the between-seed variability of the deployable selection outcome. It
does \textbf{not} include within-seed resampling of target-test speakers, so it
is not comparable to the paired intervals used elsewhere, and its width is
limited by having five observations. The same estimator is applied to the
oracle column and to the oracle gap, so the three columns of
Table~\ref{tab:headline} are on a common basis.

\paragraph{Interpretation of the oracle column.} The oracle column in
Table~\ref{tab:headline} reports the best target macro-F1 present in the grid
for each pair and seed. Because it is selected using target-test scores, no
source-only protocol can attain it. It is a benchmark for the grid as
configured, not a result. The maximum of a set of noisy scores is biased
upward, so the oracle column is an optimistic summary of this target set rather
than an estimate of achievable performance.

\paragraph{Discrepancy summaries.} The discrepancy columns describe fitted
maps, not predictions. The ladder discrepancy columns are candidate-row means
without intervals, and other discrepancy summaries state their own aggregation.
Cells of the frame-sensitivity sweep share seeds and feature sets. Their
correlations are therefore descriptive, and pooled independence-based
intervals are not used as evidence of a population-level sign change.

\paragraph{Multiple comparisons.} A primary family of seven contrasts in each
of the two directions was \textbf{pre-specified in code before the frozen
confirmatory grid was run}. It comprises the five aligned rungs against
\texttt{none} and two layer-aggregation contrasts. Holm--Bonferroni correction
\cite{holm1979sequential} is applied across exactly these 14 tests. Holm's
procedure is uniformly more powerful than Bonferroni's at the same family-wise
error rate. A false-discovery-rate procedure was not used, because the family
is small and pre-specified and family-wise control is the stricter guarantee.
A bootstrap with 2000 replicates cannot resolve $p$-values below $1/2000$, so
adjusted $p$-values at this resolution floor are marked with $<$ in
Table~\ref{tab:primary}. Comparisons outside the primary family are reported as
such. When such a comparison supports a \emph{null} claim, for example that a
difference is negligible, we report a bound rather than a test, because failing
to reject a null hypothesis is not evidence for it. When it supports a positive
claim, correction is applied within that comparison's own set, and both the raw
and the corrected $p$-values are given.

\subsection{Experimental scope}
\label{sec:scope}

The main grid is a reduced factorial design: 2 directions $\times$
3 backbones $\times$ 5 seeds $\times$ 6 rungs $\times$ layer aggregation
$\times$ 5 classifier families, with inner grids over $\varepsilon$ and
$\lambda$. It comprises 4986 runs. A smoke gate and a screening stage pruned
only the inner grids, using \texttt{source\_val} evidence alone. Three probes
supplement the grid: a 13-layer sweep (2340 runs), a CORAL shrinkage asymptote
probe (120 runs) and a shift decomposition (120 records). No run failed. All
results carry the frozen configuration tag \texttt{grid-freeze-v3}, and
Supplementary Section~S10 describes the provenance controls.
